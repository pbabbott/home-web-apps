# Exodus - UI (home-hud)

[← Project Exodus](./README.md)

- **`/exodus/sources`** — table of sources with their linked host, and an Add Source modal. The host is optional.
- **`/exodus/sources/[id]`** — the latest job with queue counts (refreshes itself every 5 seconds while a job is active), Start Job, Mark Complete, Cancel Job (with confirmation), failed directories (with a Retry button only while their job is still active; a finished job's failures say to start a new job), a "Browse inventory" link, and job history.
- **`/exodus/inventory`** — a browser for a source's inventory, with review (below), under the Exodus nav menu (Sources, Jobs, Inventory) and linked from each source page ("Browse inventory"). A Source selector at the top (`?source=<id>`) picks whose inventory to show; a missing or unknown source falls back to the first one. It starts at the latest job's root and lists a folder's direct children (folders link into themselves, with a breadcrumb trail back up); "Everything beneath it" lists every descendant with full paths, and the Type filter narrows to files or folders. Sorted by path, 100 per page with Next/First page links. All state lives in the URL (`source`, `path`, `recursive`, `type`, `review`, `after`), so a view can be bookmarked or shared, and the page is server-rendered with no client-side fetching. Switching source resets the folder to that source's job root. **Review:** each row shows its disposition badge and has a checkbox (header checkbox selects the page); with rows selected, an action bar applies Mark candidate / Not needed / Needs review to all of them in one bulk request, and a Review filter narrows the list. Selection is per page. A refused bulk (an excluded item cannot be a candidate) shows the API's message and changes nothing.
- **`/exodus/rules`** — all exclusion rules, global and per source, with an Add Rule modal (applies to, path, scope, reason) and Remove with confirmation. Server actions post to the API; humans can create global rules here, the agent cannot.
- **`/exodus/audit`** — the audit log, newest first, filterable by source and event type (`?source=`, `?type=`), 50 per page with Newest/Older links (`before` cursor). Each row gets a one-line description built from the event's `details` (`lib/audit-display.ts`).
- **`/exodus/jobs`** — jobs across all sources, filterable by source through a `?source=<id>` URL parameter.
