# Exodus Backup: Design (proposal)

[← Project Exodus](../README.md)

**Nothing in this folder is built.** It is an exploratory design for copying approved inventory items to an NFS destination. It lives apart from the rest of `docs/exodus/`, which describes what exists, so proposals are not mistaken for facts about the system. When a part is implemented, its facts move into the main Exodus docs (data model, API, processing) and this folder shrinks or goes away.

- [Design](./design.md) - the proposal: entities, lifecycle, verification, coverage, API, phases, risks, acceptance criteria.
- Decision record, in order:
  - [Questions, rounds 1 and 2](./questions-round-1-2.md) - round 1 answered; round 2 unanswered (its recommendations were applied as defaults and confirmed in round 4).
  - [Questions, round 3](./questions-round-3.md) - answered.
  - [Questions, round 4](./questions-round-4.md) - answered.
